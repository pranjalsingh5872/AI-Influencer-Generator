## 🚀 Running the Campaign Generator CLI

To generate a new custom 30-day runbook:

```bash
# Generate all 3 persona campaigns
python generate_campaign.py --persona all

# Or generate for a specific persona
python generate_campaign.py --persona mother_sator
python generate_campaign.py --persona grandmother_may
python generate_campaign.py --persona fit_midlife_guru
```
